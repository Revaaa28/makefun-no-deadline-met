Entry for the make.fun competition [One Line, No Deadline Met](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce).

A program/v1 entry: `main.py` writes one single-line joke excusing a missed deadline to `/output/entry.txt`. The line is fixed, so every run produces byte-identical output within the gate (UTF-8, 1–200 characters, single line).

The line:

> Sorry it's late — I hit snooze on the deadline nine times and it finally did what snoozed things do and vanished.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
